# ChronoLearn App - Mobile Wireframing Case Study

### **Note on Wireframes**
This project was built on top of low-fidelity wireframes created during the ideation phase. The high-fidelity UI screens represent the refined structure and flow derived from those initial wireframes, along with user research, personas, and documented design thinking as per task requirements.

---

## App Screens

The following high-fidelity UI screens have been created for the ChronoLearn app:

1. **Welcome Screen** - App onboarding and introduction
2. **Choose an Era Screen** - Historical period selection
3. **Era Details Screen** - Detailed information about selected era
4. **Journal Entry Screen** - User learning journal interface  
5. **My Timeline Screen** - Personalized learning timeline

*All screen files are uploaded in this repository.*
