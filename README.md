# ChronoLearn App - Mobile Wireframing Case Study

### **Note on Wireframes**
This project was built on top of low-fidelity wireframes created during the ideation phase. The high-fidelity UI screens shown below represent the refined structure and flow derived from those initial wireframes, along with user research, personas, and documented design thinking as per task requirements.

---

## App Screens

1. **Welcome Screen** - App landing page
2. **Choose an Era Screen** - Era selection interface  
3. **Era Details Screen** - Historical period information
4. **Journal Entry Screen** - User journaling interface
5. **My Timeline Screen** - Personal learning timeline

*Note: High-fidelity UI screen files are uploaded in the repository.*
