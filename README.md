# ChronoLearn - Mobile Wireframing Case Study

## Objective
Design high-fidelity UI screens for ChronoLearn, a History Learning App. This project is built on top of low-fidelity wireframes created during the ideation phase.

## Tools Used
- Figma
- GitHub

## Features
- User Research
- User Personas
- User Flow
- High-Fidelity UI Screens
- Design Thinking Documentation

## Screens
1. Welcome Screen
2. Choose an Era Screen
3. Era Details Screen
4. Journal Entry Screen
5. My Timeline Screen
